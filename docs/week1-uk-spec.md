## 1. 项目一句话

给热爱文学和旅行的人做一本个性化的旅行书：地图上的每个地方，都连着写到它的书和句子；读者可以收藏、规划、记录自己的旅行和阅读。

## 2. Week 1 范围

### 2.1 本周要交付

1. 一个打开即用的网页（双击 `index.html`，无需安装、无需服务器、可离线）。
2. 开场动画：旋转的地球展开成平面世界地图，文字浮现，然后飞到英国。
3. 英国 12 个大区可点击，四类地点标记，点开读摘句、看原文。
4. 按书名、作者、地点搜索。
5. 我的旅行（收藏、去过、行程、统计）和我的书单（想读、已读、收藏、笔记），数据存在浏览器本地。
6. 英文为默认语言，可切换中文。
7. 内容达到第 6.5 节的数量目标，且 12 个大区每个至少有 1 条摘句。

## 5. 功能规格

### F1 开场动画（Intro）— P0 ✅（真机帧率待测）

**目标**：参考 [TravelScope](https://www.markuslerner.com/travelscope/)。打开网站时，一个旋转的地球展开成整张平面世界地图，然后文字浮现，最后停在世界首页（11-03 起不再自动飞到英国）。

**实现方式**：独立的 Canvas 覆盖层，位于地图之上。每个顶点同时计算两个位置：球面位置（正射投影，含 3D 深度）和平面位置（与主地图相同的墨卡托投影）。用一个 0–1 的系数在两者之间插值。动画结束时，覆盖层的画面必须与下面 SVG 地图的世界视图**像素对齐**，然后淡出交接。

**分镜与时间**

| 段 | 开始 | 时长 | 内容 | 缓动 |
|---|---|---|---|---|
| 0 加载 | 0 s | ≤ 0.5 s | 纸色背景，居中一行小字 “Opening the atlas…”；数据加载完成即进入下一段 | — |
| 1 地球进场 | 0.5 s | 2.0 s | 灰绿海面的地球从 80% 缩放到 100%，同时自转约 200°，最终让欧洲和英国朝向正面 | 旋转用 quintic out，缩放用 quadratic out |
| 2 展开 | 1.0 s | 2.0 s | 球面展开成平面世界地图（与第 1 段重叠 1.5 s） | cubic in-out（原定 exponential，实测展开只占 0.4 s 像闪过，改为 cubic） |
| 3 交接 | 3.0 s | 0.4 s | Canvas 淡出，SVG 世界地图显现；英国 12 个大区的水彩色晕开 | ease-out |
| 4 文字 | 3.2 s | 1.2 s | 标题 “The Reader's Atlas” 淡入并轻微上移；0.4 s 后副标题 “Start from a line, arrive at a place” 淡入 | ease-out |
| 5 进入 | 4.5 s | 0.4 s | 世界首页在下面接手：同样的标题、同样的位置（实测像素一致），覆盖层淡出；地图停在世界视图，侧栏保持收起 | ease-out |

总时长约 4.9 秒。

**视觉**
- 球体：海面用 `--sea`，边缘加径向渐变阴影营造立体感，外圈一圈淡淡的大气光晕。
- 陆地：未开放的国家用 `--world-land`；英国的轮廓在第 2 段末尾开始显出大区水彩色。
- 背面半球：只画轮廓、透明度 0.15，避免穿帮。

**规则**
- [x] 点击、按任意键或滚动滚轮，立即跳到最终状态。
- [x] 系统设置了“减少动画”（`prefers-reduced-motion`）时不播放，直接显示最终状态。
- [x] 每次打开或刷新页面都播放（用户 11-06 决定；之前是同一次浏览会话只播一次）。带地点、书、大区的链接也先播动画，播完再飞到链接指向的页面，刷新不会丢掉当前页。只有系统设了“减少动态效果”或 `?intro=0` 时不播。`ra.introSeen` 键不再使用。
- [x] 动画数据用 Natural Earth 1:110m 国家边界，文件 ≤ 250 KB（`data/intro-geo.js`：141 KB，176 个国家，10,021 个点）。
- [x] 开场期间右侧栏、地图标题、指南针、缩放按钮、图例、标记和标签隐藏；结束后进入世界首页（见 F2）。
- 测试参数：`?intro=1` 强制播放，`?intro=0` 关闭，`?intro=1&debug=1` 播放结束后在左下角显示实测帧率（用于真机验收）。
- 网址带页面路由（如 `#/place/whitby-abbey`）时不播放，直接打开该页面。

**验收**
- [ ] 2020 年以后的 MacBook Air 上 Chrome 和 Safari 帧率 ≥ 50 fps。（11-03 无头 Chromium 实测 59.6 fps；真机用 `index.html?intro=1&debug=1` 读数，待测）
- [x] 交接时 Canvas 与 SVG 的海岸线偏差 ≤ 2 px，没有可见的跳动。（11-03 像素比对：最佳偏移 0 px，吻合度 98.6%，差异来自 1:110m 与 1:50m 的精度差）
- [x] 动画结束后所有交互立即可用，控制台无报错。
- [x] 跳过、减少动画、每会话一次三条规则都生效。

### 6.4.1 覆盖面复核（11-05 起：`node tools/check_coverage.js`，每批数据开工前和做完后各跑一次）

**为什么要有这一步。** 11-05 补作家朝圣地时，我是从“库里已有的作者”里找缺朝圣地的人，库里根本没有的作者（拜伦、雪莱）就看不到；选书一直是从“书里写到英国地名”出发，同样看不到没收进来的大作家。只拿库里的东西对照库里的东西，查不出缺了谁。

**规则：**

1. **名单从外面来。** `tools/canon.json` 由 `tools/build_canon.py` 根据公开名单生成，每条都标了出处：西敏寺诗人角（安葬和纪念的作家）、作家故居名单（维基百科 Writer's home、Slow Travel 英格兰作家故居）、苏格兰 / 威尔士 / 北爱尔兰官方旅游网站列的文学景点、BBC Big Read 前 100 名里背景在英国真实地点的书。不凭记忆往里加；确实要补，写明出处。
2. **分两级。** 一级：有作家故居或博物馆、葬在诗人角、或有 Big Read 前 50 名的书（背景是虚构地点的除外）。二级：名单上其余的人和地方。
3. **检查五件事：** 名单上的作家库里有没有书；名单上的故居、墓地、纪念地库里有没有；有的话，是否关联到库里每一位相关作家（诗人角、勃朗特故居这类多人共用的地方要关联到每一位）；Big Read 的书有没有；一个朝圣地关联了某位作家的一本书，他在库里的其他书有没有一起关联。另外列出没有任何摘句或场景说明的书。
4. **不做的要写下来。** 决定不做的条目写进 `tools/coverage-decisions.json`，写明理由和日期（比如版权、书的背景是虚构地点）。一级缺口要么补上、要么有决定，否则检查退出码为 1。
5. **选题从缺口开始。** 每批数据从检查报告的缺口里挑，不再从库里已有的内容往外想；做完再跑一次，结果写进变更记录。

### 6.6 摘句审核流程

1. 从公有领域全文（Project Gutenberg、维基文库、青空文库）复制原句，不凭记忆录入。
2. 核对版本：书名、章节、标点与所用版本一致，`location` 写到章或节。
3. 英译：优先使用公有领域旧译本；没有就自译，标 `own`。
4. 审核人确认地点关联成立后，把 `status` 改为 `reviewed`。
5. 现有草稿全部按此流程重新核对。
6. 同一段摘句里，书中相邻的句子或段落用换行连接；不相邻的部分之间单独一行 `…`。核对脚本按 `…` 分段逐段比对，所以漏写 `…` 会被当作不符（11-03 第二批里有两条因此被查出并改正）。
7. 排版统一：直引号 `'` `"`；古登堡的 `--` 写成破折号 `—`；去掉表示斜体的下划线；章节开头的大写字（如 “IN the first place”）按正常大小写录入。

## 8. 技术规格

### 8.1 架构

- 纯静态文件，没有构建步骤。`<script>` 依次加载：`geo.js` → `books.js` → `places.js` → `lines.js` → `intro-geo.js` → `vendor/maplibre-gl.js` → `basemap.js` → `i18n.js` → `intro.js` → `app.js`。样式和脚本链接带版本号（如 `?v=4`），改动后加一，避免浏览器用缓存的旧文件；11-03 起 `books.js`、`places.js`、`lines.js` 也带版本号，改数据后同样加一。
- 数据挂在全局：`window.RA_GEO`、`window.RA_DATA`、`window.RA_I18N`。
- 投影：Web 墨卡托，世界宽 1000 单位；纬度截断在 ±85°。
- 主地图用 SVG：视图变换作用在一个 `<g>` 上，描边用 `vector-effect: non-scaling-stroke`；标记组反向缩放，保持像素大小不变。
- 开场动画用 Canvas 2D，结束后移除。
- 街道底图（`js/basemap.js`，A-12）是 SVG 下面的一层 MapLibre 画布：`init` 建图，`sync` 跟随 SVG 视图，`setRegions` / `setHighlight` 画大区底色和悬停选中色，`setBlockers` 放置标签占位，`setLanguage` 切换地名语言。分层、标签和海岸线规则见 `docs/map-layers.md`。

### 8.3 地图数据流程

`tools/build_geo.py` 读取 Natural Earth 的 1:10m 一级行政区和 1:50m 国家边界：
1. 坐标量化到 0.004°；
2. 英国 232 个单元按 ITL1 归入 12 个大区；
3. 只出现一次的边就是大区外轮廓；
4. 输出 `data/uk/geo.js`（11-09 起按国家出文件，世界轮廓另出 `data/world-geo.js`；配置在 `tools/countries.json`，见 plan-week2-5.md R-1/R-2）。

开场动画另用 1:110m 国家边界，输出 `data/intro-geo.js`（P0，随 F1 一起做）。
