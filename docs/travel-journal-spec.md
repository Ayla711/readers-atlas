## 1. 一句话

标记“我去过”之后，用户可以在这个地点下写自己的旅行日志、上传自己拍的照片；这些记录汇总到“我的旅行”，成为一本按时间排列的个人文学旅行日记。

## 2. 为什么等后端

- 照片体积大，浏览器本地存储（localStorage，约 5 MB）放不下，也不适合放。
- 日志是用户自己写的内容，丢了无法恢复；必须有账号和服务器存储，能跨设备、能备份。
- 现在的“去过 / 心愿单 / 近期行程”只存在这台电脑的浏览器里（见 F8 和 8.2），上线后端时要一并迁移。

11-04 决定先把前端页面做出来，方便演示和调整交互；存储暂时放在浏览器里，见下面 2.1。

## 3. 用户故事

1. 我刚去过巴斯，打开“巴斯”，点了“我去过”，想记下那天看到的泵房和读到的《诺桑觉寺》那句话，再配几张自己拍的照片。
2. 我去过同一个地方两次（比如 2024 年和 2026 年各去一次牛津），想分开记两篇。
3. 回家后在“我的旅行”里翻看所有去过的地方，按时间看自己的旅行日记。
4. 写日志时想标明“这次是带着哪本书去的”。
5. 不想要了可以改、可以删；删照片、删日志前要确认。

## 4. 功能范围

### 4.1 入口

| 位置 | 条件 | 显示 |
|---|---|---|
| 地点页，三个按钮下方 | 已点“我去过” | 新的一节 **My visits / 我的到访**：已有的日志列表 + “Write about this visit / 写下这次旅行” 按钮 |
| 地点页 | 未点“我去过” | 不显示这一节（不鼓励给没去过的地方写日志） |
| 我的旅行 → Places I've been | 有日志的地点 | 地点行显示第一张照片缩略图和日志篇数 |
| 我的旅行 | 有任意日志 | 新增入口 **Travel diary / 旅行日记**：所有日志按到访日期倒序排列 |

### 4.2 一篇日志包含

| 字段 | 必填 | 说明 |
|---|---|---|
| 到访日期 | 否（11-04 改为选填） | 可以填具体日期、只填年月、只填年份，或者不填；不填的显示“未记日期”，在旅行日记里排在最后，按年份筛选时不出现 |
| 正文 | 否 | 纯文本，支持换行；建议上限 5000 字 |
| 照片 | 否 | 0–20 张；每张可写一句说明；可拖动排序；第一张作为封面 |
| 同行的书 | 否 | 从这个地点关联的书里选（也可以搜任意一本书），可多选 |
| 标题 | 否 | 不填时用“地点名 · 日期”显示 |

正文和照片至少要有一样，否则不能保存。

### 4.3 编辑器（弹窗或侧栏内展开，沿用现有“安排行程”弹窗的样式）

- 日期选择、正文输入框、照片上传区（点击选择或拖进来，支持多选）、同行的书、保存 / 取消。
- 上传前在浏览器里把照片缩到长边 2048 px、转成 JPEG，并**去掉 GPS 等位置信息**（保留拍摄时间，可用来建议到访日期）。
- 上传中显示每张照片的进度；失败的那张可以重试，不影响其他照片和正文。
- 未保存就关闭时提示“有未保存的内容”；正文草稿在本机临时保留，防止误关丢字。

### 4.4 显示

- 地点页 “My visits”：每篇一张卡片，显示日期、封面照片、正文前三行、同行的书；点开看全文和全部照片。
- 照片点开为大图浏览（左右切换，Esc 关闭，手机上可滑动）。
- 自己的照片和地点自带的 Wikimedia 照片要明显区分：地点照片在说明上方，带署名行；自己的照片在 “My visits” 里，不需要署名。
- 旅行日记页：按日期倒序，每篇显示地点名（可点回地图）、大区、封面、摘要；顶部可按大区或年份筛选。

### 4.5 和现有功能的关系

- **取消“我去过”**：如果这个地点已有日志，弹出确认：“这里有 N 篇日志。取消‘去过’后日志仍会保留，可以在旅行日记里找到”——日志不随之删除；要删日志须单独删。
- **近期行程**：行程日期到了之后，可以在行程那一行提示“去过了吗？标记去过并写日志”。（可选，第二步再做）
- **统计**：“我的旅行”顶部的数字不变；可考虑加“写了 N 篇日志”。
- **地点 id 变化**：日志挂在地点 id 上；改 id 时必须保留旧 id 到新 id 的对应，不能让日志变成“孤儿”（见 11-04 测试记录）。

### 4.6 隐私

- 默认只有本人看得到。
- 第一版不做公开分享；以后如果要做分享链接或公开日记，单独设计，并且分享前再次提醒照片里是否有人脸、门牌等个人信息。

## 5. 后端需要提供的能力（实现时细化）

| 能力 | 说明 |
|---|---|
| 账号 | 登录后才能写日志、传照片；未登录时 “Write about this visit” 按钮提示先登录 |
| 日志存储 | 按用户保存日志（见 6 的数据结构），支持增删改查、按地点查、按日期排序分页 |
| 照片存储 | 对象存储；服务器端再生成缩略图（如 400 px 和 1200 px 两档）；单用户总容量设上限 |
| 迁移 | 首次登录时，把浏览器里已有的“去过 / 心愿单 / 近期行程 / 书单 / 笔记”导入账号 |
| 导出 | 用户可以下载自己的全部日志和照片（ZIP，含一个 JSON 或 Markdown 索引） |
| 删除 | 删除日志时同时删除其照片；删除账号时全部删除 |


## 8. 验收标准（实现时用）

1. 只有标记“我去过”的地点能写日志；一个地点可以有多篇。
2. 正文、照片任意一样即可保存；保存后刷新、换设备登录都还在。
3. 上传的照片不含 GPS 信息（用工具读取 EXIF 验证）。
4. 取消“我去过”不会删除日志；删除日志会删除其照片。
5. 地点页、“去过的地方”列表、旅行日记三处显示一致。
6. 中英文界面都没有另一种语言的残留文字。
7. 照片加载不拖慢地图：地点页只加载缩略图，点开再加载大图。
8. 手机宽度（约 400 px）下编辑器和大图浏览可用。
